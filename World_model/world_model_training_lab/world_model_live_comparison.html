World Model Control Lab

Train four compact world-model-inspired controllers on the same damped double integrator, then load the training JSON here to run each trained neural policy in real time. Compare JEPA, DeepJEPA, DreamerV3-inspired, and Dreamer4-inspired agents under identical environment settings.

Load JSON generated by the Python trainer to use trained neural policies.
Training honesty: the included script performs real PyTorch gradient updates and exports trained policy weights, but these are lightweight research-inspired toy agents—not official DreamerV3, Dreamer4, JEPA, or DeepJEPA reproductions. The browser executes the exported trained encoder/actor networks. It does not train neural networks itself.
